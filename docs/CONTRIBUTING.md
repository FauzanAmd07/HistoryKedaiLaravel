# Panduan Kontribusi HistoryKedai

Terima kasih atas minat Anda untuk berkontribusi pada proyek HistoryKedai!

## Standar Commit

Proyek ini menggunakan **Conventional Commits**:
- `feat:` untuk penambahan fitur baru.
- `fix:` untuk perbaikan bug.
- `docs:` untuk perubahan pada dokumentasi.
- `style:` untuk kerapian kode (tanpa mengubah logika).
- `refactor:` untuk restrukturisasi kode tanpa menambah fitur.
- `test:` untuk penambahan unit atau feature test.

## Alur Pengerjaan (Workflow)
1. Fork / Clone repository.
2. Buat branch baru untuk fitur Anda (`git checkout -b feat/nama-fitur`).
3. Lakukan **Atomic Commit** untuk tiap perubahan file/fitur logis.
4. Buat Pull Request (PR) ke branch `main`.
