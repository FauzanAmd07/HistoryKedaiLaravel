# HistoryKedai - Sistem Informasi Manajemen Kedai Kopi

[![Laravel Version](https://img.shields.io/badge/Laravel-11.x-red.svg)](https://laravel.com)
[![PHP Version](https://img.shields.io/badge/PHP-%3E%3D8.2-blue.svg)](https://php.net)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Aplikasi web manajemen Point of Sale (POS) dan riwayat transaksi kedai kopi berbasis framework Laravel dan Tailwind CSS.

## 🚀 Fitur Utama
- **Kasir & Transaksi POS:** Pencatatan pesanan cepat dengan metode pembayaran QRIS/Tunai.
- **Manajemen Menu & Kategori:** Pengelolaan katalog produk lengkap dengan upload foto.
- **Manajemen Karyawan:** Hak akses bertingkat untuk Admin, Kasir, dan Pemilik Kedai.
- **Laporan Penjualan:** Laporan transaksi harian, bulanan, dan grafik performa kedai.
